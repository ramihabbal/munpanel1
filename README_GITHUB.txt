HHHSMUN shared Supabase version

1. Run SUPABASE_SETUP.sql once in Supabase SQL Editor.
2. Put index.html, styles.css, hhhsmu-logo.png, and this README directly in your GitHub repository root.
3. Open the GitHub Pages site. The header should say “Shared storage connected”.
4. Upload a PDF/DOC/DOCX from Conference Resources or Delegate Portal. It should appear in Supabase Storage > conference-files.

If the header says “Shared storage not connected”, do not upload files yet; fix the Supabase setup first.
